# 家庭车库：启动、部署与备份

当前版本 v0.6，运行环境 Node.js 24+。前端和 API 必须一起运行。

## 在 Mac 上继续用

```bash
npm ci
npm run dev
```

开发服务仍固定 5173，iPad 使用终端的 Network 地址。升级后重启旧开发进程。运行服务的 Mac 需要保持在线、不休眠。

正式运行可先停止开发进程，再执行：

```bash
npm run build
npm start
```

静态页面和 API 都由同一个 Node 服务提供。默认端口 5173，生产端口可通过 PORT 改变。不要仅把 dist 上传到静态托管。

默认数据库在当前项目的 `data/garage.sqlite`，包含小朋友、加盐口令哈希、会话及车库。可用环境变量 GARAGE_DB 指定其他路径；开发、正式服务和管理命令必须指向同一数据库，才能看到同一份用户和作品。

## NAS / Docker

仓库包含 Dockerfile 和 compose.yaml，使用 Node.js 24 和持久化命名卷，不需要外部数据库或付费服务。

在 NAS 的项目目录运行：

```bash
docker compose up -d --build
docker compose logs -f garage
```

访问 `http://NAS的局域网IP:5173/`。Mac 和 iPad 都访问这个服务，才能共享车库。如果 Mac 和 NAS 各自启动独立数据库，它们就是两个不同的家庭车库。

更新代码后再次执行 `docker compose up -d --build`。不要使用 `docker compose down -v`，它会删除保存作品的命名卷。

本轮提供部署配置，未在 NAS 上部署。局域网可以使用当前 HTTP 方式；若通过公网访问，应经 HTTPS 反向代理，并把 GARAGE_SECURE_COOKIE 设为 1。反向代理需保留原 Host，以便同源校验。当前是家庭共用入口，头像列表对能访问该服务的人可见，不是公共多家庭注册平台。

## 忘记口令

只有拥有服务端终端权限的家长可以重置。先列出 ID：

```bash
npm run admin -- list
npm run admin -- reset-pin 完整用户ID
```

按终端提示输入新的 4 位口令，不把口令作为命令行参数。重置后该用户已有会话全部失效，车库作品保留。

Docker 环境对应命令：

```bash
docker compose exec garage npm run admin -- list
docker compose exec garage npm run admin -- reset-pin 完整用户ID
```

连续错误 5 次会使该用户暂锁 10 分钟；同一来源累计失败 30 次也会暂锁。来源按直接连接 IP 计算，在反向代理下多个设备可能共享该限制。创建用户每个来源每 10 分钟最多 10 次。

## 备份和迁移

### 作品文件

登录后点页头的小朋友名字，可以下载本次作品 JSON。另一台设备登录同一用户或其他明确选定用户后，通过「导入作品备份」查看清单、确认导入。

导入会保留当前改装，合并已保存作品和备份中非默认的当前改装，按造型和名字去重。超过 6 辆时整次拒绝，不会只导入一部分。作品备份不包含口令和会话。

旧浏览器数据不会被删除。应在原来的浏览器与地址中登录、确认导入，再到其他设备查看。

### 整个家庭数据库

先正常停止服务，然后复制整个 `data/` 目录（如存在 sqlite-wal 和 sqlite-shm 文件一并保留）。恢复时同样先停止服务，再用备份目录替换，最后启动。不要在运行中仅复制 sqlite 主文件，未合并的更新可能还在 WAL 中。

Docker 下可以停止服务后从容器复制：

```bash
docker compose stop garage
docker compose cp garage:/app/data ./garage-backup
docker compose start garage
```

恢复到现有容器的数据卷时（先自行保留当前数据备份）：

```bash
docker compose stop garage
docker compose cp ./garage-backup/. garage:/app/data/
docker compose run --rm --user root --entrypoint chown garage -R node:node /app/data
docker compose start garage
```

建议为不同时间的备份使用不同目录，避免覆盖唯一备份。数据库备份包含身份和会话，不要提交到 Git 或放进网页静态目录；`.gitignore` 已排除本地数据库。

## 检查命令

```bash
npm test
npm run test:server
npm run test:e2e
npm run build
```

浏览器测试使用固定的独立端口 5174 和系统临时数据库，不会复用用户正在运行的 5173 服务。请不要在同一台机器同时运行两套浏览器测试。
