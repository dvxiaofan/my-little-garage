# 小小车库：轻改装台

**版本：v0.2**  
**日期：2026-09-13**  
**状态：已实现，15 项状态／车模／保存测试与 12 项浏览器测试通过，正式构建已检查。**  
**依据：家长授权「按你分析接着搞」，延续「亲子试玩 → 轻改装 → 一键试跑」的建议顺序。**

本轮先实现轻改装。亲子试玩尚无实际反馈；本轮选择依据是孩子会自行改装积木车、喜欢大轮胎与高底盘，并主动向爸爸妈妈展示作品。

## 一次怎么玩

打开小车库 → 点「改一改」→ 选颜色、轮胎、底盘高度、车顶装备 → 给车起名字（可以一键起名）→ 存进车库 → 回到「玩一玩」，开门、亮灯、压一压 → 下次打开继续玩，或从「我的小车」找回作品。

## 本轮范围

| 内容 | 行为 |
| --- | --- |
| 玩法切换 | 「玩一玩」「改一改」两个入口，共用一辆三维小车 |
| 车身颜色 | 橙、蓝、绿、红、黄；车门、前盖、后箱等车漆一起变化 |
| 轮胎 | 公路轮、越野轮、大脚轮；尺寸、胎纹与轮毂可区分，备胎跟随变化 |
| 底盘高度 | 原来高、高一点、再高点；车身升高、弹簧加长，车轮继续接地 |
| 车顶装备 | 不装、行李箱、小帐篷；与车身一起运动 |
| 名字 | 最多 12 个字，爸爸可帮忙输入，也可点击「帮我起名」 |
| 作品保存 | 最多保存 6 辆，保留颜色、轮胎、高度、车顶与名字；相同作品不重复保存 |
| 继续改装 | 改过的作品另存成新作品，不覆盖已有作品；可取出任意已保存小车 |
| 作品管理 | 可移走一辆，并撤销本次打开期间最近一次移走；存入新作品后结束这次撤销 |
| 自动记住 | 当前造型与名字自动记在当前浏览器；刷新后部件、灯光、悬挂回到起始状态 |
| 恢复 | 「重来」重置动作和视角，保留造型；「恢复原样」恢复最初造型和名字，保留已存作品 |

所有核心选择都用单击完成，不要求拖拽、输入数字或认读大量文字。保留首版默认静音和现有动作。此处是有限选项的改装，尚未实现自由积木拼装。

## 保存约定

作品存在这台电脑的当前浏览器中，不上传、不跨设备同步。清除浏览器网站数据会清除作品。如果浏览器拒绝保存或空间不足，允许继续玩并明确提示本次作品没有持久保存，不把它显示为「下次还能找到」。

作品名按普通文字显示；异常、过期或损坏的数据不能阻止三维车库打开。

## 验收重点

1. 选择后可立即观察真实三维变化，所有已打开部件与灯光状态保持。
2. 不同轮胎、高度与减震组合下，轮胎仍接地、弹簧长度合理、动作能完成。
3. 最高底盘配大脚轮和帐篷时，常用视角能看清整辆车。
4. 保存两种不同造型，刷新后可分别找回；恢复原样、重来不会清空作品。
5. 作品满、重复保存、移走与撤销、损坏或不可用的存储都有明确行为。
6. 桌面与窄屏没有横向溢出；按钮、弹窗与起名支持键盘焦点操作。
7. 运行首版动作回归，构建通过，并在浏览器实际检查画面。

一键试跑、道路对比与更自由的拼装留到下一阶段；实际孩子的兴趣与操作习惯仍需爸爸陪同验证。
