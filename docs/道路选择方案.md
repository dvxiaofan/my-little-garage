# 小小车库：道路选择

日期：2026-09-29。版本：v0.5。
依据：家长确认「按你的建议开始补充道路选择」，承接轻改装需求中后续道路对比。

## 本轮体验

在「玩一玩 → 跑一跑」上方提供三个带路形图标的大按钮：

| 道路 | 可以观察什么 |
| --- | --- |
| 平路 | 车身保持水平，车轮随行驶转动 |
| 连续小坡 | 两侧同高，车辆前后俯仰 |
| 交错起伏 | 两侧错开起伏，四轮分别升降、车身左右倾斜 |

默认连续小坡。先选路，再点「跑一跑」，本轮仍为约 22 秒；系统减少动态效果模式沿用约 8 秒。行驶期间道路按钮禁用，文字提示停下后可换路。结束后回展台并恢复试跑前的部件开合，灯光保持。

「重来」取消试跑并恢复车辆动作，保留改装和所选道路。刷新恢复默认道路；道路不写入作品数据。改装、视角切换仍可在试跑时使用。

这是机械动作观察，不模拟抓地力、动力、碰撞或通过能力，也不把更大的轮胎描述为一定更快。道路编辑、驾驶控制不在本轮范围。

## 实现要点

- 三种预设高度函数共用 96 单位周期，起点和终点留足整个轮距的平坦区域。
- 可见路面、车辙与四轮采样使用相同的道路选项与高度函数。
- 换路重用既有几何、材质，更新顶点、法线和包围范围。
- 路面基准与轮胎接触基准对齐；试跑时隐藏展台地板，避免地板遮住路面低谷，结束恢复。
- 道路按钮使用原生按钮及 aria-pressed，支持键盘和触屏。

## 验证

- 27 项单元测试通过：新增三种路面边界、周期性、起止接地，以及换路后地面和车辙网格一致性检查。
- 18 项浏览器回归通过：含每种道路的完整试跑、实际俯仰/侧倾差异、结束后部件与灯光恢复、试跑中重来与换路、改装保留。
- iPad 尺寸（820 × 1180）模拟触屏和 390px 窄屏操作通过；已检查截图，无新增遮挡或横向溢出。本轮新增道路仍待真实 iPad Safari 试玩。
- TypeScript 检查与生产构建通过；Three.js 分块约 602 KB 的既有提示仍在。
