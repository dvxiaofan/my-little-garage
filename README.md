# 小小车库

一个给小小车迷的三维汽车互动网页：转一转观察越野车，打开车门、前盖和后箱，点亮车灯，看看悬挂怎样压缩、回弹。现在也可以换颜色、轮胎、底盘高度和车顶装备，给自己改的小车起名字、存进车库。

**当前版本：v0.2 · 轻改装台。** 本轮范围见[轻改装需求](docs/汽车小车库-轻改装需求.md)。

模型由程序构建，包含简化内饰、发动机、后箱和独立悬挂。运行时使用本地资源，无需账号、API Key 或付费服务。

## 打开试玩

当前开发地址：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)。

在这台 Mac 上，之后可以双击 docs 目录里的「启动小车库.command」。它会在需要时安装项目依赖、启动网页并打开浏览器；如果同一地址的小车库已经运行，会直接打开现有页面。新启动服务的终端窗口需要保持打开，关闭时可按 Control + C。

也可以在当前目录使用终端。需要 Node.js 22.18 或更新版本；本次使用 Node.js 24 验证。

    npm install
    npm run dev

首次准备依赖需要联网。依赖安装后，车模、文字、样式、字体和声音都不依赖第三方在线资源。若默认端口已被其他项目使用，以终端显示的地址为准。

## 怎么玩

点「玩一玩」摆弄小车：

- 鼠标拖动：从不同角度看车。也可直接点「前面」「侧面」「后面」。
- 车门、前盖、后箱：分别点击打开，再点一次关闭，可以同时打开。
- 车灯：切换前灯和尾灯，换视角后保持状态。
- 压一压：播放悬挂压缩与回弹；播放中避免重复叠加，结束后可以再试。
- 回正：只恢复观察角度，保留已打开的部件和灯光。
- 重来：恢复车门、前盖、后箱、灯光、悬挂及视角的初始状态，保留改装造型和名字。
- 声音：默认关闭，可主动开启短促、低音量的操作反馈，没有背景音乐。

点「改一改」当小小改装师：

- 车身颜色：橘子橙、天空蓝、森林绿、番茄红、太阳黄。
- 轮子：公路轮、越野轮、大脚轮；轮胎大小、胎纹、轮毂和备胎一起改变。
- 底盘：原来高、高一点、再高点。车身升高，轮胎继续接地，可以切回「玩一玩」压一压。
- 车顶：不装、行李箱、小帐篷。
- 名字：爸爸可帮忙输入，最多 12 个字；点名字旁的骰子也能自动起名。
- 存进车库：保存当前造型与名字。改装后另存新作品，同样的作品不会重复占位。
- 恢复原样：换回最初的橙色越野小勇士，已存作品不受影响。

画面右上方的「我的车库」最多放 6 辆作品，点小车卡片就能开出来。可移走一辆并在本次打开期间「放回来」；存入新作品后结束上一次移走的撤销。

## 下次还能找到吗

当前造型和名字会自动记住，作品车库也会保存。刷新后车门、前盖、后箱、灯光和减震恢复初始状态，改装造型保留。

保存使用当前浏览器的网站数据，仅在同一浏览器、同一网页地址下可见。清除网站数据、使用另一个浏览器或更换访问端口，不会自动带上这些作品。没有账号、上传和跨设备同步。浏览器不允许保存或空间不足时，会明确提示只在本次保留，仍可继续玩。

以电脑和鼠标为主要体验；窄屏已作基础布局适配。

## 第一次陪孩子玩

先由爸爸打开网页、示范一次开门，再让孩子自由尝试。可以把家里的玩具车拿来，一起找方向盘、比较车灯或按一按减震。

优先观察孩子是否操作得起来、主动重复什么、想向你讲什么。真实兴趣与使用习惯仍需亲子试玩反馈。

## 项目结构

| 位置 | 用途 |
| --- | --- |
| src/vehicle.ts | 车辆几何结构、可动部件、灯光、悬挂 |
| src/controller.ts | 部件目标状态、连续操作与减震动画 |
| src/garage.ts | 三维场景、光照、视角、渲染和资源释放 |
| src/customization.ts | 改装选项、尺寸、名字与数据校验 |
| src/design-store.ts | 当前造型与作品车库的本地保存、去重、移走与恢复 |
| src/workshop.ts | 改装面板、作品预览、起名与车库弹窗 |
| src/main.ts | 页面结构、按钮和反馈文案 |
| src/style.css、src/tokens.css | 布局、配色、适配与交互状态 |
| src/sounds.ts | 可关闭的短音效 |
| tests/ | 状态、车模与浏览器回归检查 |
| docs/screenshots/ | 实际运行截图 |
| docs/改进建议与后续方向.md | 代码审阅后的改进建议与优先级，接手前建议阅读 |

技术栈：TypeScript、Vite、Three.js。三维模型与贴图均在项目内构建，未购买或下载外部车辆模型。

## 验证和构建

    npm test
    npm run test:e2e
    npm run build

浏览器检查优先使用本机 Google Chrome，不读取个人浏览器资料。在其他电脑上，可先使用「npx playwright install chromium」安装测试浏览器，或通过 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指定浏览器程序。

生成可分发的静态文件后，可在本机预览：

    npm run preview

构建结果位于 dist。无需直接打开该目录里的 HTML 文件，应通过本地预览服务访问。原始需求与访谈文档保留在 docs 目录，后续外部发布时只发布构建结果。

## 当前边界

当前是单车展示、机械动作演示和有限选项的改装；悬挂用于直观观察，尚未实现真实道路行驶或工程物理模拟，也不是自由积木拼装。后续优先考虑一键试跑，再依据孩子反馈决定更自由的创造玩法；具体建议与排序见[改进建议与后续方向](docs/改进建议与后续方向.md)。实体玩具录入和云端保存尚未实现。
