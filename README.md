# 小小车库

一个给小小车迷的三维汽车互动网页：转一转观察越野车，打开车门、前盖和后箱，点亮车灯，看看悬挂怎样压缩、回弹。可以换颜色、轮胎、底盘高度和车顶装备，给自己改的小车起名字、存进车库，再选一条道路跑一圈。

**当前版本：v0.6 · 家庭车库，多设备找回小车。** 改装范围见[轻改装需求](docs/汽车小车库-轻改装需求.md)，试跑见[一键试跑方案](docs/一键试跑方案.md)，外观复刻见[车型复刻方案](docs/车型复刻-越7方案.md)。

模型由程序构建，外观按一款真实方盒子越野车的照片神似复刻（不用真实车标与车型名），包含简化内饰、发动机、后箱和四轮独立悬挂。运行时使用本地资源，小朋友身份与作品保存在自家的服务端，无需第三方账号、API Key 或付费服务。

## 打开试玩

当前开发地址：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)。

在这台 Mac 上，之后可以双击 docs 目录里的「启动小车库.command」。它会在需要时安装项目依赖、启动网页并打开浏览器；如果同一地址的小车库已经运行，会直接打开现有页面。新启动服务的终端窗口需要保持打开，关闭时可按 Control + C。

也可以在当前目录使用终端。需要 Node.js 24 或更新版本（使用内置 SQLite）；本次使用 Node.js 24 验证。

    npm install
    npm run dev

开发服务固定使用 5173 端口；如果端口被占用，会报错退出，不会自动更换端口。停止占用端口的服务后再启动。

同一局域网的 iPad 可在 Safari 中打开终端显示的 Network 地址（例如 `http://192.168.1.100:5173/`）。Mac 上继续使用 `http://127.0.0.1:5173/`。保持终端运行、Mac 不休眠；iPad 上不能用 `127.0.0.1` 访问 Mac。Mac 的局域网 IP 仍可能变化，固定端口不会固定 IP。

首次准备依赖需要联网。依赖安装后，车模、文字、样式、字体和声音都不依赖第三方在线资源。

## 小朋友入口

第一次打开，点击「添加小朋友」，填写名字、选择头像、设置并确认 4 位数字口令。之后点自己的头像输入口令即可进入；名字可以相同，系统生成的唯一 ID 区分身份。

这是一个家庭共用的入口：所有设备都能看到这个家庭的小朋友列表。会话最长 12 小时，期间刷新继续进入；点击页头「换小朋友」退出并回到入口。

同一台 Mac 运行服务时，iPad 打开它的 Network 地址，选择同一个小朋友，即可读取同一份作品。请等页头显示「已保存到家庭车库」后再切换设备。两台设备同时打开不会实时联动；重新进入或在车库管理中读取最新数据。已打开的旧页面修改时，如检测到另一台设备更新，会提示冲突，不会覆盖新作品。

## 怎么玩

点「玩一玩」摆弄小车：

- 鼠标拖动：从不同角度看车。也可直接点「前面」「侧面」「后面」。
- 车门、前盖、后箱：分别点击打开，再点一次关闭，可以同时打开。四扇车门一起开；后箱像真正的越野车一样铰链在车尾右侧、门从左往右横摆打开，把手在左侧自由边，备胎挂在门上偏右的位置一起摆出。
- 车灯：切换前灯和尾灯，换视角后保持状态。
- 压一压：播放悬挂压缩与回弹；播放中避免重复叠加，结束后可以再试。
- 选择道路：平路、连续小坡、交错起伏。平路看轮子转动，小坡看前后俯仰，交错起伏看左右车轮分别升降；默认选连续小坡。试跑中不能换路，结束或点「重来」后可以再选。道路选择在本次打开期间保留，刷新回默认，不随作品保存。
- 跑一跑：展台变成选中的道路，小车原地前进约二十秒：轮子转动，四个轮子各自随路面起伏，弹簧各自伸缩，车身跟着俯仰侧倾。跑之前会自动关上车门、前盖、后箱，跑完再打开；灯光保持。跑的时候仍可拖动视角、切换观察角度，也可以去「改一改」换装备。
- 回正：只恢复观察角度，保留已打开的部件和灯光。
- 重来：恢复车门、前盖、后箱、灯光、悬挂及视角的初始状态，保留改装造型和名字。
- 声音：默认关闭，可主动开启短促、低音量的操作反馈，没有背景音乐。

点「改一改」当小小改装师：

- 车身颜色：大地金、天空蓝、森林绿、番茄红、太阳黄。
- 轮子：公路轮、越野轮、大脚轮；轮胎大小、胎纹、轮毂和备胎一起改变。
- 底盘：原来高、高一点、再高点。车身升高，轮胎继续接地，可以切回「玩一玩」压一压。抬高后车门下方会自动出现侧踏板，方便司机上下车。
- 车顶：不装、行李箱、小帐篷。
- 名字：爸爸可帮忙输入，最多 12 个字；点名字旁的骰子也能自动起名。
- 存进车库：保存当前造型与名字。改装后另存新作品，同样的作品不会重复占位。
- 恢复原样：换回最初的大地金越野小勇士，已存作品不受影响。

画面右上方的「我的车库」最多放 6 辆作品，点小车卡片就能开出来。可移走一辆并在本次打开期间「放回来」；存入新作品后结束上一次移走的撤销。

## 下次还能找到吗

当前造型和名字会自动记住，作品车库也会保存。刷新后车门、前盖、后箱、灯光和减震恢复初始状态，改装造型保留。

作品存到运行服务的电脑上，默认数据库位于 `data/garage.sqlite`。只要访问的是同一个服务，换浏览器或换设备，登录同一小朋友就能找回。停止服务后暂时不能登录和保存，重新启动后数据仍在。

- 页头明确显示保存中、已保存、网络失败或版本冲突。失败时保留当前页面的改装，重试成功前不要关闭页面。
- 点击页头小朋友名字管理车库：下载作品备份、导入备份、备份当前内容并读取服务端最新数据。
- 老版本的浏览器作品不会自动归入某个小朋友。首次进入发现旧作品时，先查看清单、确认所属小朋友，再点「确认导入」。重复作品去重；合计超过 6 辆会整次拒绝，原数据保留。
- 旧作品按浏览器与原网页地址存储。如果 iPad 看不到 Mac 的旧作品，请先在 Mac 原来的地址登录并导入。
- 口令连续输错 5 次会暂锁 10 分钟；忘记口令由家长在服务端执行 `npm run admin -- list` 查找完整 ID，再执行 `npm run admin -- reset-pin 用户ID`，按提示输入新口令。重置会撤销该用户已有登录。

详细范围见[家庭车库方案](docs/家庭车库方案.md)。

## 第一次陪孩子玩

先由爸爸打开网页、示范一次开门，再让孩子自由尝试。可以把家里的玩具车拿来，一起找方向盘、比较车灯或按一按减震。

优先观察孩子是否操作得起来、主动重复什么、想向你讲什么。真实兴趣与使用习惯仍需亲子试玩反馈。

## 项目结构

| 位置 | 用途 |
| --- | --- |
| src/vehicle.ts | 车辆几何结构、可动部件、灯光、四轮独立悬挂与轮子转动 |
| src/controller.ts | 部件目标状态、连续操作、减震动画与试跑周期 |
| src/garage.ts | 三维场景、光照、视角、渲染、越野路切换和资源释放 |
| src/terrain.ts | 三种道路的高度函数、路面网格与切换 |
| src/customization.ts | 改装选项、尺寸、名字与数据校验 |
| src/design-store.ts | 车库数据、去重、移走与恢复，以及旧浏览器数据兼容 |
| src/cloud-store.ts | 服务端保存、失败重试、版本冲突、作品导入 |
| src/family.ts | 小朋友入口、会话、车库管理与迁移确认 |
| server/ | HTTP API、SQLite、静态服务、家长口令管理与集成测试 |
| src/workshop.ts | 改装面板、作品预览、起名与车库弹窗 |
| src/main.ts | 页面结构、按钮和反馈文案 |
| src/style.css、src/tokens.css | 布局、配色、适配与交互状态 |
| src/sounds.ts | 可关闭的短音效 |
| tests/ | 状态、车模与浏览器回归检查 |
| docs/screenshots/ | 实际运行截图 |
| docs/改进建议与后续方向.md | 代码审阅后的改进建议与优先级，接手前建议阅读 |
| docs/亲子试玩反馈-第一次.md | 孩子提出的问题、处理结果与待定方向 |
| docs/一键试跑方案.md | 「跑一跑」分步实现方案与执行记录 |
| docs/车型复刻-越7方案.md | 按真实车型复刻外观的分步方案与执行记录 |

技术栈：TypeScript、Vite、Three.js、Node.js 24、SQLite。三维模型与贴图均在项目内构建，未购买或下载外部车辆模型。

## 验证和构建

    npm test
    npm run test:server
    npm run test:e2e
    npm run build

浏览器检查优先使用本机 Google Chrome，不读取个人浏览器资料。在其他电脑上，可先使用「npx playwright install chromium」安装测试浏览器，或通过 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指定浏览器程序。

构建完成后，可预览包含 API 的应用：

    npm run preview

构建结果位于 dist。家庭车库需要配套 API，不能仅把 dist 上传到静态托管。生产环境运行 `npm run build` 后执行 `npm start`，默认同样监听 5173。浏览器测试使用独立的 5174 端口和系统临时数据库，不复用家庭服务或真实作品。

## 当前边界

当前是单车展示、机械动作演示、有限选项的改装和三种预设路面的试跑；试跑是跑步机式的动画（车不动、路在动），不是可操控的驾驶，也不是工程物理模拟；不模拟抓地力、速度优势或障碍通过判定，更不是自由积木拼装。后续依据孩子反馈决定是否做可操控驾驶或更自由的创造玩法；具体建议与排序见[改进建议与后续方向](docs/改进建议与后续方向.md)。已支持同一家庭服务下的用户与跨设备保存；实体玩具录入、公共注册平台和实时多设备协作尚未实现。
